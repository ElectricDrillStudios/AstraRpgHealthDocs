# Installation instructions

## Importing Astra Health and its samples

> [!NOTE]
>Unity is asking publishers to upload UPM packages via a new porta, however packages with dependences (such as Astra Health) are not supported yet by the new portal.
>Because of this, I had to upload this package as a standard `.unitypacakge`. This means that samples, opposed to Astra Framework, will already be available upon import.

1. Make sure you have Astra Framework v2.2.0+ imported in your project
2. If you are willing to open and use the Sample Scene, import also TextMeshPro Essentials. Click on "Window > TextMeshPro > Import TMP Essential Resources". Find out more about the samples in the [Samples documentation](./samples.md).
3. From the package manager, import Astra Health. You can find the package in the "My Assets" section.
