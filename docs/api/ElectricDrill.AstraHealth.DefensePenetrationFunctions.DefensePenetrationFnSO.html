CalculatePiercedDefense(long, long, StatSO, in ReductionContext, bool)

Same as CalculatePiercedDefense(long, long, StatSO, bool), for functions that also depend on the entities involved (a constant that grows with the attacker's level, another stat of the attacker). The damage pipeline always calls this overload.

public virtual double CalculatePiercedDefense(long piercingStatValue, long defensiveStatValue, StatSO defensiveStat, in ReductionContext context, bool applyClamp = true)

Parameters

piercingStatValue long

The attacker's piercing stat value used to reduce defense.

defensiveStatValue long

The defender's original defense stat value to be reduced.

defensiveStat StatSO

The defensive stat object used to clamp the result within its min/max bounds.

context ReductionContext

The entities involved in the hit: their levels and stats. Valid only during the call.

applyClamp bool

Whether to apply stat clamping to the result.

Returns

double

The reduced defense value (clamped if applyClamp is true).

Remarks

The default implementation ignores context and forwards to the abstract overload, so existing implementations keep working unchanged. Override it to use the context.
