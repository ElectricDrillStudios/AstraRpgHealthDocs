Gets whether the damage calculation pipeline records a per-step amount trace (Records). The trace backs Step lifesteal, is readable by user code from any damage-resolution listener, and feeds the negative-amount pipeline diagnostic — at the cost of one small list allocation per damage instance. Defaults to true (identical in the editor and in builds); turn it off only after confirming nothing reads Records and no step-based lifesteal is configured.

When true, generic and type-specific lifesteal amounts are summed into a single heal. The HealSource of the damage type takes precedence over the generic one (falls back to the generic source if only generic lifesteal is active or type has no source set).
